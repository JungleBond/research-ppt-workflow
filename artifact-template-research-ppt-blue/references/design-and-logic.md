# 设计与叙事规则

## 先分清任务

论文汇报围绕一个科学问题：为什么要研究、已有方案缺在哪里、本文改变了哪一步、怎样验证、证据支持到哪里。章节可用“问题／方法／实验／讨论”。不要把论文的章节目录逐字搬上去，也不要逐图孤立介绍。

应用讲座围绕少数大场景：每个场景沿“任务要求／输入／方法执行的步骤／输出／检查”展开。传统与新方法的比较放在具体工序中，写清改变了什么；不能无依据地估算节省比例。

跨论文汇报中，只有同一个实验系统才能画成贯通流程。不同研究的组合必须明确切换。单篇论文的探索实验与正式评估也要区分。

## 页面衔接合同

先按 [听众理解与个人表达](audience-and-voice.md) 建立“开场可懂—中段加深—证据验证—回到问题”的理解顺序。每页的复杂度取决于前面已经建立的知识，不按论文段落长度分配。

每页只有一个主要问题。上一页必须为本页提供问题、条件、机制或证据；本页的下一页字段解释为什么要继续，不只是“接下来介绍结果”。

例如：提示可能含糊 → 模型为何需要多个输出 → 多输出怎样影响评估 → 自动指标与人类评价为何会不同。

讲稿在翻页前提出下一页要回答的问题，但不把下一页重要结论提前讲完。图的方向、颜色、部位和比较对象必须与口播一致。讲稿不用“左下角注释告诉我们”等制作性语言。

相邻实验页优先保持可追踪的具体对象。例如先展示六类数据的图像，再比较同名数据的分数，最后跟踪其中一个异常结果；不能只靠“接下来看看”连接不同材料。对结果的解释要落到图中的数据集、曲线、条件或实例，避免只写“评价不同”“设计得到支持”。

关键术语第一次进入论证时，在画面上给最短可用解释。指标说明应含定义或读法，基线名称应说明是什么方法。只在备注中解释、画面上仍全是缩写，不算完成。原图画出了探索性分支或另一套训练设置时，当页就说明，不能等若干页后才澄清。

## 固定视觉系统

| 项目 | 默认规则 |

| 比例 | 16:9；原始 12192000 × 6858000 EMU；制作画布 1280 × 720 |
| 字体 | Microsoft YaHei / 微软雅黑；全部可编辑字体 ≥18 pt |
| 换算 | 本工具 1 CSS px = 0.75 pt；24 px = 18 pt |
| 主色 | #005D97，章节深底 #004675，标题标记 #00B0F0 |
| 正文 | #172D3C；来源和次要信息 #526674 |
| 辅色 | #DAE3F6 淡蓝，#E4F3DA 淡绿，#FCE6D5 淡橙；语义稳定 |
| 导航 | 灰色顶栏，当前章节白底深字；章节数可变 |
| 标题 | 青色小标记＋蓝色粗体；通常 38 px，允许 36—44 px |
| 正文区域 | x=34—1246，y=155—640；两栏间距通常 28—48 px |
| 页脚 | 蓝底白字，短研究名称＋页码，24 px |
| 来源 | y≈650，24 px；一行作者年份和图号，完整 URL 在备注 |
| 表格 | 蓝色表头，浅色交替行；首列强调；足够的内边距 |
| 结束页 | 白底、蓝色横带、模板原阴影；仅“谢谢大家” |

这些坐标是版式起点，不是把所有内容塞进同一网格的规定。给大图足够面积，减少把证据切碎的小框。

同一套色彩可以用在浅色整块、细标题带和无底色的文字区。连续多页都采用相同三色三块时，回看内容是否真的分成三个同等层级；若只是把说明、条件和限制凑成三个框，应改为与论证关系一致的布局。

## 版式选择

- 大图＋侧说明：原图占约 60%，右侧两三组具体解释。适合装置、实验结果和流程。
- 横向结构图＋下方解释：宽图占上半区，下面解释输入、计算和输出。核心小字放大或用中文原生标签。
- 分阶段说明＋局部证据：阶段各有工序、操作、产物，配关键原图，不能只有“阶段一、二”。
- 结果图＋条件和解释：保留轴、基线、样本范围，右侧交代读法、结果、限制，不再重复整份表格。
- 原生表格＋证据小图：用于实际比较，控制每格文字量；不能将任意几句话都变成表格。
- 两图并列：比较对象、时间点或实验条件明确时使用，图下说明差异来自什么。
- 章节目录：优先复用 `assets/toc_reference.pptx` 的蓝色侧栏、白色内容区和编号横条。章名在横条中居中，展示研究递进；短汇报一个总目录即可，不机械添加过渡页。

## “饱满”与“拥挤”

正文出现超过约四分之一的连续空洞时，先问是否缺证据、图太小、说明挤在角落、图片本身留白太大。它是人工检查线索，不是像素达标规则。

修复顺序：裁掉纯白边 → 不破坏信息地放大图 → 对齐图文关键位置 → 改用合适的双栏或上下结构 → 补已有证据的必要解释 → 合并低信息量页。

禁止新增重复总结、无来源统计、装饰图标或把内容放大到相互挤压。细节页可以文字较多，但必须有清楚层级。

## 图像与媒体

证据图默认 contain，不裁掉坐标、尺度、关键部位。cover 主要用于封面照片，检查主体。子图记录原页码和坐标。复用同一大图不同部分，必须服务新问题；换文件名不算新素材。

论文拼图不等于可投影的附图。听众需要辨认每个对象或名称时，优先选有代表性且与后页结果一致的子图，分别放大并给原生标签，明示选取范围。标签同时有英文名和中文说明时，可分两行，不让相邻标签视觉上连成一句话。选择性展示不能隐瞒负面结果或改变总体结论。

视频只有任务需要时才加。备注含播放前观察点、操作提示、播放后解释；优先内嵌，检查重复并实际测试播放。不靠联网维持主线。示例任务不放视频。

## 文案删改

删掉且不影响理解的总结、自夸、标签和制作过程标记就删。保留具体对象、条件、对比与出处。标题长短自然，不能强行四字化，也不能每页写成“AI 如何……从而……”。

“共同关注目标、行动与结果”“这意味着新的可能”“关键不在于……而在于……”不能作固定页尾。真正结论对应本页证据，有必要才出现。
